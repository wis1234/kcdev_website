Accessibilité

Notre Engagement

Le KEMT Center s'engage à rendre son site web accessible à tous, y compris aux personnes handicapées. Nous suivons les directives d'accessibilité Web Content Accessibility Guidelines (WCAG) 2.1.

Caractéristiques d'Accessibilité

  • Navigation au clavier complète
  • Contraste de couleur adéquat pour la lisibilité
  • Textes alternatifs pour les images
  • Structure HTML sémantique
  • Tailles de police ajustables
  • Sous-titres sur les vidéos
  • Support des lecteurs d'écran

Ajustements de Police

Vous pouvez ajuster la taille du texte dans les paramètres de votre navigateur. Utilisez les raccourcis clavier:

  • Augmenter: Ctrl + (ou Cmd + sur Mac)
  • Diminuer: Ctrl - (ou Cmd - sur Mac)
  • Réinitialiser: Ctrl 0 (ou Cmd 0 sur Mac)

Compatibilité des Appareils

Notre site est conçu pour être accessible sur des appareils mobiles, tablettes et ordinateurs de bureau. Il fonctionne avec tous les navigateurs modernes et lecteurs d'écran.

Problèmes d'Accessibilité

Si vous rencontrez des difficultés d'accessibilité sur notre site, veuillez nous contacter immédiatement:

Email: accessibility@kemtcenter.org

Nous nous engageons à résoudre tout problème rapidement.

Déclaration de Conformité

Nous nous efforçons de maintenir la conformité WCAG 2.1 niveau AA sur l'ensemble de notre site web. Pour plus d'informations, consultez notre déclaration d'accessibilité complète.
